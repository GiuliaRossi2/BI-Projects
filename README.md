## Project 2: Student Performance Factors Analysis
[Presentation project2](./Project2/Analysis_BI2.pdf)

**Objective & Analytical Methodology**
The goal of this project was to analyze an educational dataset containing **19 behavioral, environmental, and demographic factors** to determine their impact on student grades.
The analysis was structured according to variable type and applied three distinct methodological approaches:
* **Binary Factors:** Evaluated using percentage differentials to make direct comparisons between distinct pairs
* **Categorical Factors:** Normalized onto a custom numerical scale to easily map and track linear trends against grade distributions
* **Numerical Factors:** Analyzed directly as continuous quantitative data to observe exact performance distributions
