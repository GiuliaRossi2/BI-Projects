# BI-Projects

## Project 1: Retail Margin Reduction Analysis

**Project Objective:**  
Analyze the drivers of profit margin reduction in a high-volume retail environment.

**Data:**  
CUSTOMERS, PRODUCTS, STORES, TICKETS, UNIT_TICKETS

**Data Processing (SQL / Python):**
- Managed high-volume transactional datasets  
- Transformed datasets to minimize information loss  
- Designed optimized join strategies aligned with analytical objectives  

**Analysis (Tableau):**
- Built interactive dashboards for multi-dimensional analysis  
- Performed root-cause analysis of margin reduction across customers, products, and stores
