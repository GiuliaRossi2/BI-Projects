# BI-Projects
This repository contains two Business Intelligence projects developed during an academic course.
The focus of both projects is data analysis, transformation, and visualization to extract meaningful business and educational insights.


## Project 1: Retail Margin Reduction Analysis
**Project Objective:**  
Analyze the drivers of profit margin reduction in a high-volume retail environment.

**Data:**  
CUSTOMERS, PRODUCTS, STORES, TICKETS, UNIT_TICKETS

**Data Processing (SQL / Python):**
- Managed and processed large-scale transactional datasets
- Performed data transformation while preserving analytical integrity
- Designed optimized join strategies for efficient analysis

**Analysis (Tableau):**
- Built interactive dashboards for multi-dimensional analysis  
- Performed root-cause analysis of margin reduction across customers, products, and stores
